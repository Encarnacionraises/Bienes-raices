# Bienes Raíces Encarnación 🏡

Sitio web oficial de **Bienes Raíces Encarnación**, agencia inmobiliaria en Encarnación de Díaz, Jalisco.

## 🌐 Ver sitio
[vienesraisesencarnacion.github.io/bienes-raices](https://vienesraisesencarnacion.github.io/bienes-raices)

## 📊 Cómo agregar propiedades
Las propiedades se administran desde Google Sheets:
- Abre el archivo de Google Sheets compartido
- Cada hoja nueva = una propiedad nueva
- Las columnas son: `nombre`, `precio`, `direccion`, `descripcion`, `tipo`, `metros`, `foto1`, `foto2`, `foto3`, `estado`
- Para `tipo` usa: `casa` o `terreno`
- Para `estado` usa: `disponible`, `apartado` o `vendido`

## 🛠️ Tecnologías
- HTML, CSS, JavaScript puro
- Google Sheets como base de datos (CSV público)
- GitHub Pages para hosting gratuito
